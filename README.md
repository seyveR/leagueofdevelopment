# Лига развития

Версия 0.3.0. Мобильное веб-приложение и PWA: ознакомительные задания для детей, подбор кружков и запись на пробные занятия. Разработка этой итерации ведётся только в `test`.

## Возможности

- Родитель: профили детей, четыре возрастных набора 3–17 лет, история и результаты, каталог, сравнение до трёх программ, избранное, отзывы и заявки.
- Организация: профиль и модерация, программы, фотографии, расписание пробных занятий, обработка заявок и CSV.
- Администратор: пользователи, модерация, программы, специалисты, тарифы, правила рекомендаций, отчёты, версии наборов и журнал действий.
- Настройки аккаунта и ребёнка, Лев и София, внутренние уведомления, выгрузка и удаление своих данных.
- Тестовые подписки и запись к специалистам. Реальных платежей нет.

Стек: React, TypeScript, Vite, FastAPI, PostgreSQL, SQLAlchemy/Alembic. Три Docker-сервиса: frontend, API и PostgreSQL; файлы сохраняются в отдельном постоянном томе.

## Запуск

Нужен Docker Desktop с Linux-контейнерами. Для новой копии скопируйте `.env.example` в `.env` и задайте длинный `POSTGRES_PASSWORD`. Существующий `.env` не перезаписывайте.

Первичная сборка требует доступа к сети:

```sh
docker compose up --build -d --wait
```

Если образы уже собраны, запуск без скачивания:

```sh
docker compose up -d --no-build --pull never --wait
```

[Приложение](http://127.0.0.1:8080/) · [Администратор](http://127.0.0.1:8080/admin) · [Организация](http://127.0.0.1:8080/partner) · [API](http://127.0.0.1:8080/api/docs)

Адреса доступны на компьютере запуска. Для публичной установки PWA нужен HTTPS; локальная проверка работает на loopback. Нативные приложения и публикация в магазинах не выполнялись.

Остановка и повторный запуск:

```sh
docker compose stop
docker compose start
```

Данные сохраняются. Не используйте `down -v` для обычной остановки. Если включён доступ DBeaver, при пересоздании PostgreSQL используйте тот же дополнительный Compose-файл публикации порта.

## Учётные записи

Родитель и организация регистрируются через интерфейс. Администратор создаётся отдельной командой, пароль запрашивается без отображения:

```sh
docker compose exec api-be python -m app.cli create-admin --email admin@example.com
```

Восстановление и подтверждение email сейчас доступны в локальном режиме одноразовых ссылок. Доставки email нет:

```sh
docker compose exec api-be python -m app.cli issue-reset-link --email parent@example.com
docker compose exec api-be python -m app.cli issue-verification-link --email parent@example.com
```

## Озвучка и ограничения

Голос и персонаж настраиваются независимо в «Настройки». Голосовые модели не скачивались после просьбы ограничить сетевую активность. Записи и образцы пока не подготовлены: доступен текст, браузерный синтез не подставляется. Подготовка и лицензии описаны в [инструкции озвучки](docs/audio.md).

Платежи работают только в явно обозначенном симуляторе. Email/SMS/push и реальные специалисты не подключены. Результаты заданий не являются диагнозом, IQ или подтверждённой оценкой способностей. Контакты начального каталога вымышлены.
