# Лига развития

Версия 0.2.1. Веб-приложение для родителей: задания для детей, результаты и подбор кружков. Интерфейс на русском языке, адаптирован для мобильного экрана и компьютера.

## Что реализовано

- Регистрация, вход и смена пароля родителя и администратора.
- Создание, редактирование и переключение профилей детей.
- 12 заданий на внимание и память для детей 7–9 лет, сохранение ответов и продолжение после перезагрузки.
- Результаты и рекомендации кружков, каталог и контактная информация.
- Обратная связь от родителей.
- Администрирование кружков и правил рекомендаций, просмотр прохождений, ответов и статистики переходов.

Данные хранятся в PostgreSQL. Стек: React, TypeScript, Vite, FastAPI, PostgreSQL и Docker Compose.

## Запуск

Нужны Git и Docker Desktop с Linux-контейнерами. Docker Desktop должен быть запущен.

```sh
git clone https://github.com/seyveR/leagueofdevelopment.git
cd leagueofdevelopment
```

Скопируйте `.env.example` в `.env` и задайте собственный длинный пароль в `POSTGRES_PASSWORD`. При повторном запуске используйте существующий `.env`.

```sh
docker compose up --build -d --wait
```

При первом запуске автоматически создаются таблицы и начальный каталог кружков.

Адреса доступны на компьютере, где запущено приложение.

## Создание администратора

```sh
docker compose exec api-be python -m app.cli create-admin --email admin@example.com
```

Замените email на свой. Команда запросит пароль дважды (10–128 символов). После создания войдите через обычную форму. Администратора нельзя создать через регистрацию родителя.

## Остановка и повторный запуск

```sh
docker compose stop
docker compose start
```

Данные сохраняются между запусками. Для их сохранения не используйте `docker compose down -v`.

Просмотр состояния и журналов:

```sh
docker compose ps
docker compose logs --tail 100 api-be mobile-app
```

## Текущие ограничения

Заявки, кабинет организации, запись и отмена занятий, календарь и оплата пока не реализованы. Кнопка «Связаться с кружком» открывает контакты и не передаёт данные родителя организации. Контакты начального каталога вымышлены. Результаты заданий не являются диагнозом или подтверждённой оценкой способностей.

`main` — сохранённая версия, `test` — ветка дальнейшей разработки.
