# Выбранные голоса

Пользователь одобрил образцы Звукограма: Лев — «Мальчик Петя», София — «Девочка Таня». Исходные MP3 сохранены в references/audio. Они читают одну пробную реплику, а не весь набор заданий. Текущая работающая озвучка пока остаётся Silero: подставлять один образец вместо разных инструкций нельзя.

job.json содержит точные тексты, стабильные номера, SHA-256 и привязку персонажей. Файлы ru-lev-texts.txt и ru-sofia-texts.txt содержат только произносимые реплики, без номеров. Они подходят для просмотра и оценки объёма. Единая длинная запись из такого файла ещё не является набором отдельных инструкций: перед подключением нужны отдельные файлы по записям job.json.

Предпочтительный следующий шаг — пакетная генерация через API выбранного сервиса после проверки тарифов, условий использования и доступности точных голосов. API-ключ хранить только локально в игнорируемом .env, не в чате и не в Git. Платные запросы автоматически не выполнялись. Альтернатива — отдельные записи через сайт с сохранением номера реплики в имени файла.

Скорость, тон и стиль должны совпадать с одобренными образцами; их значения пока не подтверждены. Перед полным пакетом проверить настройки на одной короткой и одной длинной инструкции. Права на использование конкретных голосов в приложении нужно подтвердить условиями сервиса.

Пересоздать список без сетевых запросов: `python tools/export-voice-job.py`.
