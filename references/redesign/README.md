# Актуальные ориентиры редизайна

- screens.png — обзор приветствия, авторизации, профилей, главной, тестов, аналитики, каталога, персонажей и прохождения.
- palette.png — палитра и семейство иконок направлений.
- liza.png — состояния Лизы и возрастные Лиги.

Копии пользовательских изображений сохранены без изменения. Они заменяют прежние визуальные ориентиры в соответствующих частях. Исходные размеры: screens 1682×735, palette 961×470, liza 1351×502. Снятые ориентировочные цвета определены в src/redesign/redesign.css: тёплый фон, фиолетовый, сиреневый, оранжевый, зелёный и жёлтый.

В public/redesign находятся отдельные вырезки иконок и небольших состояний Лизы; полные экраны не используются как интерфейс. school.svg и max.svg — созданные векторные иллюстрации, не точные копии презентационного рисунка. Для крупного изображения Лизы/Макса и точного воспроизведения иллюстративной манеры нужны оригинальные прозрачные экспорты персонажей по состояниям; имеющихся обзорных картинок недостаточно для качественного увеличения. Нужны также оригиналы эмблем трёх Лиг и полноразмерные иллюстрации школы/класса. Пока Лиги оформлены цветными карточками с возрастным названием без вырезок низкого качества.

Для читаемости используется системный Segoe UI с кириллицей и Arial как запасной шрифт. Файлы шрифтов из внешней сети не загружались. Маленький текст обзорной картинки не воспроизводится буквально.
