# Подготовленная русская озвучка

Проверено по официальным источникам 27.10.2026: [Silero README](https://github.com/snakers4/silero-models), [LICENSE_CIS](https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS), [реестр моделей](https://github.com/snakers4/silero-models/blob/master/models.yml). Выбран адаптер Silero v5_cis_base_nostress: для этой конкретной серии автор указывает MIT, включая русские варианты ru_ перечисленных голосов. Конфигурация связывает ru_zara с Софией, ru_bogdan со Львом; выбор явный, пол по имени программно не определяется. Лицензия PyTorch — BSD-style; лицензия приложения не меняется от вызова отдельной команды подготовки.

Русские специализированные Silero v5_ru опубликованы на иных, некоммерческих условиях; подмена модели без проверки запрещена. У Piper текущий движок GPL-3.0, лицензии голосов отдельные: у [irina](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/irina/medium/MODEL_CARD) указана неизвестная лицензия датасета, у [dmitri](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/dmitri/medium/MODEL_CARD) — CC0 датасет, но fine-tuning от lessac требует отдельной оценки. Поэтому эти голоса не включены как разрешённые к коммерческому использованию.

27.10.2026 загрузка возобновлена по просьбе пользователя, крупные файлы скачивались последовательно с ограничением 1 МБ/с. Модель загружена и создано 72 WAV-файла: 36 текстов для каждого голоса. Записи скопированы в постоянный том /data/audio вместе с LICENSE_CIS. Модель: SHA-256 `0405777e332906f0644e08a680f7cfdc2137ea864090079c1fdd30a43c1b8761`. Генератор: PyTorch 2.6.0+cpu, NumPy 2.3.5, Python 3.12; не входит в зависимости API.

Оба реальных образца успешно декодированы и проиграны в Edge headless через Nginx/API. Для всех 72 записей проверены WAV, длительность и ненулевой сигнал. Это техническая проверка воспроизведения; естественность, ударения и соответствие персонажу требуют ручного прослушивания.

В настройках выберите голос, нажмите «Прослушать образец». Для инструкций включите «Озвучка заданий» и сохраните настройки. Для самостоятельного запуска инструкции включите также «Автоматическое воспроизведение»; ограничения autoplay браузера сохраняются. Настройки ребёнка могут перекрывать настройки родителя.

Повторная подготовка на Windows: создайте отдельную .tts-venv, установите backend/requirements-audio.txt, выполните `./tools/prepare-audio.ps1`. Скрипт проверяет зафиксированный SHA-256, использует уже загруженную модель, генерирует недостающие записи и копирует кэш в работающий API. Веса, окружение и кэш исключены из Git. На новой машине генерацию нужно выполнить заново либо восстановить файловый том из резервной копии.

Низкоуровневая команда без скачивания:

```sh
python -m app.prepare_audio --model models/v5_cis_base_nostress.pt --expected-sha256 0405777e332906f0644e08a680f7cfdc2137ea864090079c1fdd30a43c1b8761 --output audio-cache
```
Команда не скачивает модель, проверяет переданный SHA-256, сохраняет версии и голоса в manifest.json. Веса и аудиокэш хранятся вне Git на постоянном томе. API только раздаёт записи. Ключ включает исходный текст, язык, голос, модель и SHA-256 весов; старый файл не подставляется для нового текста. В материал памяти голосовые инструкции не включают скрываемые фигуры.

Перед включением автоозвучки требуется ручная проверка образцов и каждой инструкции: ударения (в CIS-серии автоматическая расстановка не обещается), числа, окончания, паузы и обрезания. Если требуется ручная разметка ударений, она должна стать отдельным версионированным полем, включённым в ключ кэша. Реальные имена и ответы детей для синтеза не используются.

Соответствие точному тексту и голосу хранится в overrides.json на постоянном томе; исходные WAV не удаляются. Новая запись имеет приоритет только при совпадении текста и наличии файла; повреждённый реестр или отсутствующий файл возвращает прежний вариант. MP3 раздаются как audio/mpeg. Импортированный набор определяется содержимым папок voices/sofia и voices/lev; сохраняйте там все используемые записи при повторном импорте.
