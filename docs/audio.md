# Подготовленная русская озвучка

Проверено по официальным источникам 27.10.2026: [Silero README](https://github.com/snakers4/silero-models), [LICENSE_CIS](https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS), [реестр моделей](https://github.com/snakers4/silero-models/blob/master/models.yml). Выбран адаптер Silero v5_cis_base_nostress: для этой конкретной серии автор указывает MIT, включая русские варианты ru_ перечисленных голосов. Конфигурация связывает ru_hye_zara с Софией, ru_udm_bogdan со Львом; выбор явный, пол по имени программно не определяется. Лицензия PyTorch — BSD-style; лицензия приложения не меняется от вызова отдельной команды подготовки.

Русские специализированные Silero v5_ru опубликованы на иных, некоммерческих условиях; подмена модели без проверки запрещена. У Piper текущий движок GPL-3.0, лицензии голосов отдельные: у [irina](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/irina/medium/MODEL_CARD) указана неизвестная лицензия датасета, у [dmitri](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/dmitri/medium/MODEL_CARD) — CC0 датасет, но fine-tuning от lessac требует отдельной оценки. Поэтому эти голоса не включены как разрешённые к коммерческому использованию.

После сообщения пользователя об обрывах интернета загрузка моделей и новых зависимостей отложена. Записи НЕ подготовлены, звучание и соответствие голосов персонажам НЕ прослушаны. Интерфейс честно показывает этот режим и использует текст, без перехода на speechSynthesis. Функциональная проверка аудиоплеера не является оценкой естественности голоса.

После разрешения загрузок: получить конкретную модель из официального models.yml, сохранить LICENSE_CIS и исходный URL в /data/models, вычислить SHA-256, установить отдельно PyTorch CPU в окружение команды генерации и выполнить:

```sh
python -m app.prepare_audio --model /data/models/v5_cis_base_nostress.pt --expected-sha256 <проверенный-sha256>
```

Команда не скачивает модель, проверяет переданный SHA-256, сохраняет версии и голоса в manifest.json. Веса и аудиокэш хранятся вне Git на постоянном томе. API только раздаёт записи. Ключ включает исходный текст, язык, голос, модель и SHA-256 весов; старый файл не подставляется для нового текста. В материал памяти голосовые инструкции не включают скрываемые фигуры.

Перед включением автоозвучки требуется ручная проверка образцов и каждой инструкции: ударения (в CIS-серии автоматическая расстановка не обещается), числа, окончания, паузы и обрезания. Если требуется ручная разметка ударений, она должна стать отдельным версионированным полем, включённым в ключ кэша. Реальные имена и ответы детей для синтеза не используются.
