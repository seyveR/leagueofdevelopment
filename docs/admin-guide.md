# Руководство администратора

Создайте администратора отдельной командой из README. Роль не предлагается в регистрации родителя. После входа откроется /admin.

Для смены собственного пароля выберите «Сменить пароль» в меню администрирования. Введите текущий пароль, новый (10–128 символов) и повторите новый. Успех возвращает на вход и завершает все сессии этой учётной записи. Данные и роль сохраняются. Управления чужими паролями через этот экран нет. При отзыве сессии извне следующий защищённый запрос или проверка при возврате к вкладке возвращает на вход; кнопка выхода также работает.

## Кружки и правила
Нажмите «Кружки и правила», затем «Добавить кружок». Укажите название, описание, возрастные границы, город, адрес, телефон, цену. URL фотографии необязателен; загрузки файлов нет. Проверьте данные и права использования фотографии.

Правило: «Любой результат» либо внимание/память; нижний и верхний пороги процента правильных ответов включительно; приоритет (выше показывается раньше); нейтральное объяснение для родителя. Не вводите оценочные ярлыки вроде «плохая память». Пороговые правила предварительные и не являются подтверждённой методикой.

Сначала применяются возраст и город из снимка завершённого прохождения, затем правило. До пяти совпадений. Новая программа создаётся с общим правилом, которое можно уточнить. При сохранении кружка и правила выполняются два запроса: если второй неуспешен, форма сохраняет id кружка и позволяет повторить без создания новой записи.

Редактирование открывает те же поля. Для удаления из новых подборов установите «Архивировать кружок» и сохраните. Физическое удаление не выполняется, исторические внешние ключи остаются целыми. Снять флажок можно для возврата в каталог. Архивный кружок не показывается в родительском каталоге или новых рекомендациях.

## Статистика
«Завершённые прохождения» — число успешных завершений, одно на сессию.
Нажмите карточку «Завершённые прохождения»: откроется список с ребёнком, возрастом, родителем, датой и результатами по вниманию/памяти. «Подробнее» открывает сохранённый результат, дату начала/окончания, версию набора и алгоритма, а также 12 раскрываемых заданий: материал, ответ ребёнка, правильный ответ и время сохранения. Данные ребёнка показываются на момент начала прохождения, результат не пересчитывается. Список содержит по 20 прохождений на странице, новые сверху.

«Переходы к кружкам из рекомендаций» — число отдельных открытий карточки через кнопку «Связаться с кружком» в рекомендациях после заданий, а не звонков или записей. Повтор одного сетевого запроса не увеличивает счётчик. Нажмите карточку для списка кружков: количество переходов, город, последний переход, отметка архива. Сортировка по числу переходов, по 20 кружков на странице. Архивирование не стирает прежние переходы. Открытия из обычного каталога не учитываются. Нулевое состояние объясняет, как появляются данные.

## Обратная связь
Раздел показывает оценку приложения, предложение, дату и идентификатор пользователя. Расширенное управление пользователями, модерация документов и кабинет организации не реализованы.

Редактор заданий отсутствует. Для изменения набора разработчик добавляет новую версию seed-данных; старое содержание начатых и завершённых прохождений менять нельзя.
