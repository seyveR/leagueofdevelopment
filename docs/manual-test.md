# Ручная проверка минимального сценария

Проверяйте по http://127.0.0.1:8080/ после готовности трёх контейнеров. Используйте вымышленные профили в локальном прототипе.

| Шаг | Ожидаемый результат |
| --- | --- |
| Регистрация родителя | Email/пароль создают parent; после обновления вход остаётся |
| Выход и вход | Выход закрывает защищённые экраны; правильный пароль возвращает профили |
| Частые правильные входы | Переключение пользователя и администратора не вызывает блокировку |
| 15 неверных входов подряд | Первые 14 — ошибка пароля, пятнадцатый — пауза на минуту; ошибки в паузе не продлевают её, правильный пароль разрешён сразу и сбрасывает счётчик |
| Смена пароля родителя/администратора | В профиле/меню есть «Сменить пароль», текущий + новый + повтор; успех возвращает на вход, старый пароль больше не подходит, новый работает |
| Ошибки смены пароля | Неверный текущий, несовпадение и короткий новый не меняют пароль и не закрывают сессию |
| Отзыв другой сессии | Войдите в ту же запись в отдельном браузере/инкогнито, смените пароль в первом; защищённое действие или возврат к вкладке во втором переводит на вход |
| Выход после отзыва | Кнопка «Выйти» из вкладки со старой сессией возвращает на вход без застревания |
| Сохранение ребёнка без согласия | Форма не отправляется; API без согласия возвращает 422 |
| Ребёнок 8 лет, город Архангельск | Профиль сохраняется и доступен после reload |
| Ребёнок 6 лет | Профиль сохраняется; кнопка набора 7–9 лет недоступна |
| Два ребёнка | Переключение показывает их собственные сессии |
| Начало | Видна текстовая инструкция, необязательная озвучка, 12 заданий |
| Ответ и reload | Открывается следующий сохранённый шаг; несохранённый выбор при reload не обещается |
| Задание памяти | Сначала материал без ответов; после скрытия только варианты; reload не возвращает скрытый материал |
| Ошибка записи | Переход блокируется, выбор остаётся; повтор сохраняет один ответ |
| Завершение | Только после всех 12 ответов; фактические показатели внимания/памяти и одна подпись о характере результата |
| Повтор завершения | Тот же результат, одна запись события completed |
| Рекомендации | До пяти кружков, соответствующих возрасту и городу; без совпадений понятное пустое состояние |
| Контакты | Кнопка открывает карточку с адресом и tel-ссылкой, не форму заявки |
| Обратная связь | Рейтинг 1–5 и предложение сохраняются; повтор запроса не создаёт дубль |
| Родитель на /admin | Отказ; запросы к /api/admin также запрещены |
| Другой родитель | Подстановка чужого child/session id возвращает 404, данные не видны |
| Администратор | Создание и редактирование кружка и правила сохраняются |
| Архив | Кружок исчезает из родительского каталога/новых рекомендаций |
| Статистика | completed увеличивается на одно завершение; club_open на отдельное открытие из рекомендаций |
| Подробности прохождений | Нажатие карточки открывает список, затем результат ребёнка и родителя; 12 заданий раскрывают ответы, обновление страницы сохраняет маршрут |
| Переходы по кружкам | Вторая карточка показывает кружки, количество переходов и дату последнего; обычный каталог счётчик не меняет, архив сохраняет историю |
| Перезапуск контейнеров | Профили, сессии, результаты, каталог и отзывы остаются; cookie-сессия в пределах срока сохраняется |
| Прямые маршруты | /profile, /admin, /feedback открываются/обновляются через Nginx |
| Мобильная ширина | На 360/390/430 px нет горизонтальной прокрутки, формы доступны |

Для имитации отказа ответа в инструментах браузера можно временно блокировать POST /api/sessions/.../answers либо использовать готовый Playwright-сценарий в отдельной базе. Не очищайте рабочую БД ради проверки.

Нормальный останов: docker compose stop. Запуск: docker compose start. Полное обновление сборки: docker compose up --build -d. Том не удаляется. Физический телефон и конкретные браузеры iOS/Android проверяйте отдельно; изменение ширины окна не равно проверке устройства.
