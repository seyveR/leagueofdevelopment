# Покрытие второй итерации

27 октября 2026. Ветка test. Это локальный вариант для проверки сценариев, не подтверждение коммерческой, научной или юридической готовности.

| Область ТЗ №2 | Состояние | Реализация и границы |
| --- | --- | --- |
| Мобильный интерфейс | Реализовано | React/TypeScript, адаптивная навигация, увеличенный текст, уменьшение движения |
| PWA | Реализовано | Манифест, иконки, service worker, экран отсутствия сети; личные API и ответы не кэшируются; публикации в магазинах нет |
| Настройки | Реализовано | Аккаунт, независимые настройки ребёнка, наследование, серверное хранение |
| Лев и София | Реализовано | Материал команды, конфигурация вариантов, приветствие/инструкция/ожидание/речь/завершение; анимация речи связана с audio playing/pause |
| Два естественных голоса | Требует разрешения загрузки | Реестр Silero CIS MIT и офлайн-команда готовы; модели и записи не загружены, образцы не готовы, звучание не проверено |
| Аудиоплеер | Реализовано | Единственный проигрыватель, отмена устаревшего запроса, остановка/смена голоса, регулировка, autoplay с явным сообщением; без speechSynthesis |
| Четыре возраста | Реализовано | Собственные сценарии 3–5, 6–9, 10–12, 13–17; по 12 заданий, без переноса сторонних тестов |
| Игровые механики | Реализовано | Выбор, память со скрытием, поиск, закономерности, сопоставление, нажатие цели |
| Адаптация | Реализовано | Два верных ответа подряд → уровень 2; ошибка → уровень 1; показанная задача, уровень, условия и версия правил хранятся на сервере |
| Показатели выполнения | Реализовано | Шесть групп фактических действий и нейтральные графики. Нажатия не являются диагностикой координации, время не интерпретируется как черта личности |
| Научная диагностика / тип мышления | Не реализуется без методики | Нет IQ, норм и распределения на визуалов/аудиалов/кинестетиков |
| История / динамика | Реализовано | Старые результаты не пересчитываются; расширенное сравнение группирует одинаковые версии, сложности и условия, требует серверного права history |
| Рекомендации | Реализовано | Обязательные возраст/город, веса интересов и правил, фильтры, объяснения; ML не добавлен |
| Каталог | Реализовано | Цена, формат, время, интерес, возраст, город; сравнение трёх, избранное, фотографии и контакты |
| Карта / расстояние | Частично | Заменяемый адаптер внешней ссылки по адресу; карты SDK, геолокация и расстояние требуют провайдера |
| Отзывы / рейтинг | Реализовано | После завершённого прохождения, модерация, рейтинг только опубликованных; нет отметки подтверждённого посещения |
| Партнёр | Реализовано | Регистрация, профиль, приватный PDF, модерация, программы, время и места, акции, заявки, собственный CSV |
| Запись / отмена | Реализовано | Явное согласие на контакт, статусы и история, проверка мест и владения, прекращение занятий по запросу родителя |
| Календарь | Частично | Датированный список записей с фильтром даты; повторяющиеся учебные группы и полный календарный план будущих занятий ещё не моделируются |
| Тарифы | Реализовано | Бесплатно один новый профиль, серверные права и срок, сохранность существующих детей при истечении |
| Платежи | Тестовый режим | Сохранённый серверный заказ, отдельное подтверждение, идемпотентность, без списаний и карточных данных. Реальный эквайринг и подписанный webhook требуют реквизитов |
| Консультации | Реализовано | Управляемый администратором каталог и время, запись и отмена, серверная защита занятого времени; тестовые карточки отмечаются явно, реальные специалисты не подключались |
| Уведомления | Реализовано внутри приложения | Статусы заявок, модерация, подписка; напоминания формируются при синхронизации центра после 30 дней; настройки влияют на новые события |
| Email / SMS / push | Требует сервиса | Адаптеры обозначают недоступность, ложного подтверждения отправки нет; SMS-вход не создавался без провайдера |
| Восстановление / email | Локальный режим | Одноразовые хешированные токены на 30 минут, защищённая административная команда; нет публичных универсальных кодов и ссылок в обычных логах |
| Администрирование | Реализовано | Пользователи/блокировка, организации, программы, отзывы, специалисты, тарифы, веса, доступность наборов, состояние аудио, журнал и отдельные метрики |
| Согласие и данные | Реализовано с оговоркой | Отзыв блокирует новые действия, собственная JSON-выгрузка, удаление с документированными исключениями; юридические тексты предварительные |
| Хранение | Реализовано | PostgreSQL, Alembic без перезаписи старых наборов, постоянный файловый том, интерфейс для замены на S3; PNG и приватный PDF, ограничения размера |
| Резервирование | Реализовано | Команды PostgreSQL + файлы, проверка контрольных сумм и восстановление только в liga_test; результаты фактической проверки — verification.md |
| Нативные приложения | Отложено по заданию | Основной формат — веб/PWA |
| Реклама / рекламодатель | Отложено | В приоритетном задании нет согласованного рекламного сценария и провайдера; сторонние трекеры не подключались |
| Публичная эксплуатация | Не проверена | Нет подтверждения 152-ФЗ, размещения в РФ, SLA, пентеста, 10 000 пользователей, iOS/Android/Safari и качества нейронных голосов |

Фактические проверки и замечания отделены от готовности функций в verification.md. Наличие таблицы или кнопки не считается подтверждением работы: основные серверные и браузерные пути проверяются на отдельной базе.
