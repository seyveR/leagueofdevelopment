# Маршруты версии 0.2.0

| Маршрут | Экран |
| --- | --- |
| / и /login | Вход, регистрация родителя |
| /home | Дети, переключение, начало/продолжение |
| /children/new и /children/:id/edit | Имя, возраст, пол, интересы, город, согласие |
| /tests | Прохождения выбранного ребёнка |
| /sessions/:id/intro | Инструкция и озвучка |
| /sessions/:id/tasks | Текущий шаг, показ/скрытие памяти, ответ |
| /sessions/:id/result | Сохранённые показатели конкретного набора |
| /sessions/:id/recommendations | До пяти программ и переход к контактам |
| /programs и /programs/:id | Фильтры возраст/город, карточка с телефоном |
| /feedback | Оценка приложения и предложение |
| /profile | Учётная запись и дети |
| /admin | Статистика |
| /admin/clubs | Каталог, редактор и правила |
| /admin/feedback | Обратная связь |

Старые /applications и локальные результаты новой навигацией не используются.
