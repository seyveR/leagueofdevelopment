# Маршруты 0.3

| Маршрут | Экран |
| --- | --- |
| /login | Вход и регистрация родителя |
| /recovery | Локальное восстановление / подтверждение по одноразовой ссылке |
| /home, /profile | Профили и личный кабинет |
| /children/new, /children/:id/edit | Создание и редактирование ребёнка |
| /tests | Наборы, история и сопоставимое сравнение |
| /sessions/:id/intro, tasks, result, recommendations | Ознакомительное прохождение и рекомендации |
| /programs, /programs/:id | Каталог, сравнение и карточка/заявка |
| /bookings | Свои заявки, активные записи и прекращение |
| /plans, /consultations | Тестовые тарифы и записи к специалистам |
| /settings, /notifications, /account | Настройки, уведомления, согласие/выгрузка/удаление |
| /partner/register | Регистрация организации |
| /partner, /partner/programs, /partner/bookings, /partner/stats | Кабинет организации |
| /admin | Отчёты о прохождениях и переходах |
| /admin/platform | Модерация и управление платформой |
| /admin/clubs, /admin/feedback | Прежний каталог/правила и отзывы о приложении |

Все защищённые данные дополнительно проверяются сервером. Прямой ввод маршрута не предоставляет права другой роли.
